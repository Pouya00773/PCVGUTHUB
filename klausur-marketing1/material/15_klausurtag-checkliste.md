# Material 15 — Klausurtag-Checkliste (auf eine Karteikarte übertragen)

## Vor Beginn
- Uhr sichtbar; auf das Blatt schreiben: Startzeit + „HA spätestens ab Min 28 (bei 3 VF) / 24 (bei 2 VF)".

## Minute 0–4: Lesen
- ALLES lesen. Operatoren einkreisen, „besonders" doppelt unterstreichen.
- Vorfragen zählen → Zeitschema: **3 VF:** 4/24/57/5 · **2 VF:** 4/20/61/5.

## Vorfragen
- Schema: Definition → 3–5 Merkmale → IGM-Bedeutung → Beispiel → Abgrenzung/Problem.
- Harte Grenze ~8 min/Frage. Hängt eine → Lücke lassen, weiter; in der Prüfrunde auffüllen.

## Hauptaufgabe
- 5–7 min Mini-Gliederung mit Zeitbudget an den Rand; Schwerpunkte ZUERST dimensionieren.
- Einstieg mit Abgrenzungsgerüst: „Ich betrachte den Markt für … Eingeschlossen … Ausgeschlossen … Direkte Kunden …"
- Volumen kompakt: „Annahme … Formel … ⇒ ca. …–… Plausibel, weil …" (4–6 Zeilen).
- Unbekannter Markt? → Cluster erkennen (kommunal? Automaten/System? Zulieferer? Anlagen? Betreiber? viele kleine Kunden?) → Clusterlogik übertragen. Annahmen als Annahmen kennzeichnen.
- Unsichere Zahlen? → Anker (80 Mio. EW, 4 Bio. € BIP …) + Herleitung + Bandbreite. Nie scheinexakt.

## Letzte 5–8 Minuten: Prüfrunde
1. Trends ↔ Fazit konsistent?
2. Kundenbild ↔ Kommunikation/Distribution konsistent?
3. Abgrenzung ↔ Volumenrechnung: dieselbe Marktdefinition?
4. Alle „besonders"-Teile ausführlich bedient?
5. Vorfragen-Lücken auffüllen.

## Mentales
- Es wird KEIN Faktenwissen über den Markt erwartet — nur sauberes Vorgehen, plausible Annahmen, Konsistenz.
- Präzise Antwort auf die konkrete Frage schlägt Textmenge.
