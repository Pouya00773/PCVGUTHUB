# Material 2 — Operatoren-Checkliste

> Vor JEDER Antwort: Operator identifizieren → Antworttiefe daran ausrichten. Die Musterklausur nutzt genau diese Verben.

| Operator | Verlangt | Verlangt NICHT | Typische Länge |
|---|---|---|---|
| **skizzieren** | Grundzüge, Struktur, Überblick in geordneter Form | Vollständigkeit, Details | kurz–mittel |
| **skizzieren Sie kurz** | nur die Kernpunkte (3–5) | jede Nebenfacette | 3–4 min |
| **beschreiben / schildern** | sachliche Darstellung (Was? Wie?) | Bewertung, Begründung | mittel |
| **erklären / erläutern** | Darstellung MIT Begründung/Zusammenhang (Warum?) | bloße Aufzählung | mittel |
| **analysieren** | zerlegen, Zusammenhänge und Wirkungen aufzeigen, strukturiert | Nacherzählung | lang |
| **abgrenzen** | explizite Ein-/Ausschlusssätze + Nachbarmärkte/Substitute benennen | vage „es gibt auch…" | eigener Absatz |
| **abschätzen** | Rechnung: Annahmen → Formel → Ergebnis/Bandbreite → Plausibilität | exakte Zahl ohne Weg | 4–6 Zeilen |
| **herleiten** | Wirkungskette von Ursache zu Ergebnis, Schritt für Schritt | Behauptung des Ergebnisses | mittel |
| **„gehen Sie besonders ein auf X"** | X wird der größte Block (bei Typ 2: ~60 % der Zeit) | X als Randnotiz | dominant |
| **„außerdem kurz Y"** | Y als knapper Katalog/Absatz | Y-Vertiefung auf Kosten von X | kurz |

## Warnregeln
1. „Besonders" schlägt alles: erst die Schwerpunkte dimensionieren, dann den Rest.
2. Nur Analyse verlangt → **keine Strategie, keine SWOT** entwickeln.
3. Jede Frage beantwortet genau das Gefragte — Menge zählt nicht, Präzision zählt.
4. Bei Aufzählungs-Teilaufgaben (Typ 1 Busse): jede genannte Teilaufgabe bekommt einen erkennbaren eigenen Abschnitt.
