# Material 9 — Buying-Center-Vergleichsmatrix (Kontrollversion)

> **Didaktik:** Am Tag 2 erst selbst aus dem Skript erarbeiten, DANN mit dieser Version vergleichen. `[Folie __]` eintragen.

| Dimension | **Kommunaler/öffentlicher Kunde** (Stadtbusse, Feuerwehr, Ampeln) | **Industrieller OEM** (Flugzeugsitze, Akkus, Kunststoffzähne-Handel) | **Privater Mittelständler/Betreiber** (Pistenraupen, Parkhaus, Gastro) |
|---|---|---|---|
| Typische Rollen | Nutzer (Fahrer/Wehr/Werkstatt), Fachamt/Technik, **Vergabestelle/Einkauf**, Kämmerei, Verwaltungsspitze, **Politik/Gremien**, ggf. Aufgabenträger + Fördergeber | Entwicklung (Design-in!), **Qualität/Zulassung**, strategischer Einkauf, Produktion/Logistik, Programm-Management | Inhaber/GF (oft Entscheider UND Genehmiger), Betriebsleiter/Nutzer, ggf. externer Berater/Bank |
| Entscheider real | Gremium auf Vorlage des Fachamts; Vergaberecht bindet | Cross-funktionales Sourcing-Board; Einkauf führt, Technik qualifiziert | Inhaber persönlich; kurze Wege |
| Mittelbindung/Risiko | hoch, haushaltsgebunden, mehrjährig; politisches Risiko | hoch + Serienrisiko (Ausfall stoppt Produktion/Zulassung) | hoch relativ zum Betrieb → Finanzierung/Leasing wichtig |
| Prozess | Bedarfsplan → Haushaltsmittel/Förderung → **förmliche Ausschreibung** (Leistungsverzeichnis, Wertungskriterien) → Zuschlag → Abnahme | Anfrage → Lieferantenqualifikation/Audit → Muster/Erprobung → **Rahmenvertrag** → Serienabrufe → laufende Bewertung | Bedarf → Messe/Händler/Empfehlung → Vorführung/Test → Verhandlung → Kauf |
| Dauer/Formalisierung | lang, maximal formalisiert | lang, hochformalisiert (Audits, Normen) | kurz–mittel, informell |
| Kaufhäufigkeit | zyklisch (Ersatzbeschaffungsprogramme) | kontinuierlich nach Nominierung | selten (alle 5–15 Jahre) |
| Zentrale Kaufkriterien | Wertungskriterien der Ausschreibung: Preis/Lebenszykluskosten, Erfüllung LV, Referenzen, Service | Qualität/Zulassung, Liefersicherheit, Zielpreis, Entwicklungskompetenz | TCO, Zuverlässigkeit, Servicenähe, Beziehung/Vertrauen, Gebrauchtwert |
| Marketingkonsequenz | LV-Kompetenz, Referenzen, förderfähige Konfigurationen, frühe Information des Fachamts (vor Ausschreibung!) | Design-in früh, Key Account Teams, Auditfähigkeit, Werksbesuche | persönlicher Verkauf/Händler, Vorführungen, Messen, Finanzierungsangebote |

**Merksatz:** Gleiches Produkt, drei Welten — die Segmentierung (Schritt 7) muss GENAU diese Unterschiede im Entscheidungsprozess begründen.
