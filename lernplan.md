# Lernplan – damit „Grundkenntnisse / im Selbststudium" wirklich tragen

Ziel: Jede Skill-Angabe, die du als „in Aneignung" listest, bis zum Gespräch/Jobstart real
untermauern. So ist die Aussage ehrlich **und** du glänzt im Interview.

| Skill | Kostenlose Ressource | Mini-Ziel (≈10–15 h) |
|---|---|---|
| **SQL** | Mode SQL Tutorial, SQLBolt, Khan Academy | SELECT/JOIN/GROUP BY sicher; eine kleine Abfrage erklären können |
| **Python** | „Python for Everybody" (freecodecamp/YouTube), Kaggle Learn | Daten einlesen (pandas), einfache Auswertung + Diagramm |
| **Power BI** | Microsoft Learn (kostenlos), YouTube „Guy in a Cube" | 1 Dashboard aus Excel-Daten bauen |
| **Lean / KVP / 5S** | „Lean Six Sigma White Belt" (gratis Zertifikat), Wikipedia-Grundlagen | 5S, Ishikawa, PDCA in 2 Sätzen erklären |
| **C#** | Microsoft Learn C# Pfad | Grundsyntax, kleine Konsolen-App |
| **SAP** | openSAP (kostenlose Kurse), SAP Learning Hub Trial | Navigations-/Modul-Grundlagen (MM/SD) auffrischen |

## Vorgehen
1. Wähle 2–3 Skills, die in deinen Zielanzeigen am häufigsten auftauchen (oft: **SQL, Power BI, Lean**).
2. Plane pro Skill 1 Woche × ~2 h. Nach ~3 Wochen sind „Grundkenntnisse" ehrlich belegbar.
3. Optional: ein kostenloses Zertifikat (z. B. Lean Six Sigma White Belt) im CV unter „Weiterbildung" ergänzen.
4. Kleine Projekte (1 SQL-Abfrage, 1 Power-BI-Dashboard) als Gesprächsstoff fürs Interview merken.
