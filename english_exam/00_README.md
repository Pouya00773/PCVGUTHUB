# Mündliche Englisch-Prüfung M3Ws – Vorbereitungs-Kit

Komplettes Lernpaket für die mündliche Prüfung in 5 Tagen. Sprachniveau bewusst
einfach gehalten (B1): **kurze, korrekte Sätze sind besser als komplizierte falsche.**

## Dateien und Lern-Reihenfolge

| Datei | Inhalt | Wann lernen |
|---|---|---|
| `01_part1_introduction.md` | Antwort-Vorlagen für alle Vorstellungs-Fragen (mit Lücken zum Ausfüllen) | Tag 1 |
| `02_part2_topics.md` | Fertige Kurzantworten zu allen 19 Fachthemen (EU, Marketing, Wirtschaft) + Vokabeln | Tag 2 + 3 |
| `03_part3_discussion.md` | Diskussions-Phrasen + Pro/Contra-Argumente für alle 5 Diskussionsthemen | Tag 4 |
| `04_lernplan_5_tage.md` | Konkreter Tagesplan mit Lerntechniken | Zuerst lesen! |

## So benutzt du das Kit

1. **Zuerst** `04_lernplan_5_tage.md` lesen – dort steht, was du an welchem Tag machst.
2. In `01_part1_introduction.md` die Lücken (`___`) mit **deinen eigenen Infos** füllen.
3. Alles **laut** üben, nicht still lesen. Sprechen kann man nur durch Sprechen lernen.
4. Antworten mit dem Handy aufnehmen und anhören – so hörst du selbst, wo es hakt.
