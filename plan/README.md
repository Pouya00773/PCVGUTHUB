# Planungsdokumente

Umsetzungsplan für eine Kaffeerösterei: rückverfolgbare Herkunft, EUDR-Konformität
und produktgebundene CO₂-Daten. Abgeleitet aus dem Kakao-Piloten von Hashgraph Group,
Merck und PwC Germany (angekündigt 08.09.2026), aber bewusst nicht kopiert.

**Rechercheschluss: 09.09.2026.** Regulatorik ändert sich — Fristen und Rechtsstand
vor Verwendung gegenprüfen.
